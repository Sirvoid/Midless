# Raylib_VoxelEngine
Voxel engine in progress programmed in C using Raylib.
![Image](https://i.imgur.com/XyDTSOS.png)

The provided build script (`build.sh`) assumes you have installed [raylib + w64devkit](https://raysan5.itch.io/raylib) in `C:\raylib`,
it will wget `stb_perlin.h` from [nothings/stb](https://github.com/nothings/stb)' main branch
before building and launching `midless.exe`.
